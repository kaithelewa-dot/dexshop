DEX SHOP — КАК ЗАПУСТИТЬ САЙТ (около 20–30 минут, бесплатно)
================================================================

В папке:
  index.html          — сам магазин
  admin.html          — админ-панель (заказы, цены, фото, контакты)
  firebase-config.js  — СЮДА нужно вставить ваши настройки (шаг 5)
  firestore.rules     — правила доступа к базе (шаг 3)
  data.js, shop.js, firebase.js — служебные файлы, не трогайте

Понадобится аккаунт Google (Gmail).


ШАГ 1. Создайте проект Firebase
--------------------------------
1. Откройте https://console.firebase.google.com и войдите через Gmail.
2. Нажмите «Create a project» (Создать проект).
3. Название: dexshop → Continue.
4. Google Analytics можно выключить → Create project → Continue.


ШАГ 2. Создайте базу данных
---------------------------
1. Слева: Build → Firestore Database → «Create database».
2. Location (расположение): выберите Europe (например eur3) → Next.
3. Выберите «Start in production mode» → Create.


ШАГ 3. Вставьте правила доступа
-------------------------------
1. В Firestore Database откройте вкладку «Rules» (Правила).
2. Удалите всё, что там написано.
3. Откройте файл firestore.rules (Блокнотом), скопируйте весь текст и вставьте.
4. В строке  request.auth.token.email == 'admin@example.com'
   замените admin@example.com на ВАШ e-mail для входа в админку
   (маленькими буквами, кавычки оставьте).
5. Нажмите «Publish» (Опубликовать).


ШАГ 4. Создайте вход в админ-панель
-----------------------------------
1. Слева: Build → Authentication → «Get started».
2. Вкладка «Sign-in method» → «Email/Password» → включите первый
   переключатель (Enable) → Save.
3. Вкладка «Users» → «Add user» → введите тот же e-mail, что в шаге 3,
   и придумайте пароль → Add user.
4. Для безопасности: вкладка «Settings» → «User actions» → снимите
   галочку «Enable create (sign-up)» → Save. Так никто другой не сможет
   зарегистрироваться.


ШАГ 5. Подключите сайт к базе
-----------------------------
1. Нажмите шестерёнку слева вверху → «Project settings».
2. Внизу, в блоке «Your apps», нажмите значок  </>  (Web).
3. Название: dexshop → «Register app» (галочку Hosting не ставьте).
4. Появится код с  const firebaseConfig = { apiKey: "...", ... }
5. Откройте файл firebase-config.js Блокнотом и замените каждое
   "ВСТАВЬТЕ_СЮДА" на значение из Firebase:
       apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId
   Кавычки и запятые сохраните. Сохраните файл.


ШАГ 6. Разместите сайт в интернете (Netlify)
--------------------------------------------
1. Откройте https://app.netlify.com/signup и зарегистрируйтесь (бесплатно,
   можно через Google).
2. Откройте https://app.netlify.com/drop
3. Перетащите ВСЮ папку dexshop-site в окно браузера.
4. Через несколько секунд сайт готов — появится ссылка вида
   https://что-то-случайное.netlify.app
5. Чтобы ссылка была красивой: Site configuration → Change site name →
   dexshop  →  сайт станет https://dexshop.netlify.app
   (если имя занято — например dexshop-kg).
6. В Firebase: Authentication → Settings → Authorized domains →
   Add domain → впишите dexshop.netlify.app (нужно для сброса пароля).

Админ-панель: https://ВАШ-САЙТ.netlify.app/admin.html
(ссылка «Вход для администратора» есть и внизу сайта).


КАК ЭТО РАБОТАЕТ
----------------
• Покупатель оформляет заказ → он сразу появляется в админ-панели
  (со звуковым сигналом, если панель открыта) и может продублировать
  его вам в WhatsApp 996708355281.
• В админ-панели вы меняете статус заказа, пишете клиенту в WhatsApp,
  меняете цены, загружаете фото товаров и меняете контакты —
  покупатели видят изменения сразу, без перезагрузки сайта.

Как обновить файлы сайта позже: Netlify → ваш сайт → Deploys →
перетащите папку ещё раз.

Свой домен (например dexshop.kg) можно купить у регистратора .kg и
подключить в Netlify: Domain management → Add a domain.


БЕСПЛАТНЫЕ ЛИМИТЫ
-----------------
Firebase (план Spark): 50 000 чтений и 20 000 записей в день —
хватит примерно на 2 000+ посетителей в день. Netlify: 100 ГБ трафика
в месяц. Если магазин вырастет — это можно расширить.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
• Админка пишет «Почти готово» → не заполнен firebase-config.js (шаг 5).
• Админка пишет «Нет доступа» → e-mail в правилах (шаг 3) не совпадает
  с e-mail входа. Исправьте и снова нажмите Publish.
• Заказ уходит только в WhatsApp, а в админку не попадает → проверьте
  шаги 2, 3 и 5.
